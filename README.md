# 🎉 年会抽奖系统

一款专为年会设计的抽奖程序，支持手机端访问，喜庆风格界面，功能完善。

## ✨ 功能特点

- 🎨 **喜庆风格UI**：中国红+金色配色，灯笼装饰元素
- 📱 **手机适配**：响应式设计，完美支持手机访问
- 🔢 **默认奖项**：内置特等奖、一等奖、二等奖、三等奖、幸运奖
- 📊 **Excel导入**：支持导入参与者名单
- 🎲 **随机抽奖**：公平的随机抽奖算法
- 🏆 **中奖记录**：实时记录并支持导出Excel
- 🚫 **防重复**：设备ID绑定，防止重复参与
- 🔊 **音效支持**：抽奖音效和庆祝音效

## 🛠️ 技术栈

- **前端**：Vue 3 + Vite + Element Plus + Pinia
- **后端**：Node.js + Express
- **数据库**：SQLite3
- **特效**：Canvas Confetti（彩带动画）+ Howler（音效）

## 🚀 使用指南

### 1. 启动系统

```bash
npm start
```

启动后会显示访问地址：
- 🖥️ 大屏幕：`http://服务器IP:3000`
- ⚙️ 管理后台：`http://服务器IP:3000/#/admin`
- 🔗 参与者加入：`http://服务器IP:3000/#/join`

### 2. 开启抽奖

1. 访问管理后台，点击"开启新抽奖"
2. 输入抽奖名称（如：2024年会抽奖）
3. 点击"初始化默认奖项"按钮，自动设置：
   - 幸运奖：10人
   - 三等奖：4人
   - 二等奖：2人
   - 一等奖：1人
   - 特等奖：1人

### 3. 导入参与者

方式一：**导入Excel**
- 准备Excel文件，包含列：姓名、部门、手机号
- 在管理后台点击"导入Excel"

方式二：**生成测试数据**
- 点击"生成50个测试人员"按钮，快速生成测试数据

方式三：**扫码加入**
- 大屏幕显示二维码
- 参与者扫码自助填写姓名加入

### 4. 开始抽奖

1. 在大屏幕页面点击"开始抽奖"
2. 名字开始滚动
3. 点击"停止抽奖"
4. 显示中奖者并播放庆祝动画

### 5. 导出结果

抽奖结束后，在会话管理页面可以导出中奖名单为Excel文件。

## 🔧 Windows部署

### 方法1：直接运行

```bash
# 在Windows云服务器上
cd lucky-draw
npm run setup
npm start
```

### 方法2：使用PM2（推荐）

```bash
# 全局安装PM2
npm install -g pm2

# 创建PM2配置文件 ecosystem.config.js
# 然后运行
pm2 start ecosystem.config.js
pm2 save
pm2 startup
```

### 方法3：Windows服务（nssm）

1. 下载并安装 [nssm](https://nssm.cc/)
2. 创建启动脚本 `start.bat`：
   ```batch
   @echo off
   cd /d D:\lucky-draw
   npm start
   ```
3. 使用nssm注册为Windows服务：
   ```batch
   nssm install LuckyDraw
   ```
4. 在nssm界面中选择启动脚本路径，设置工作目录

## 🎯 注意事项

1. **首次启动**：会自动创建SQLite数据库文件
2. **数据安全**：数据库文件位于 `server/database.sqlite`，请定期备份
3. **端口占用**：默认使用3000端口，如需修改请编辑 `server/src/app.js`
4. **防火墙**：确保服务器防火墙开放3000端口

## 🐛 常见问题

**Q: 二维码加载失败？**  
A: 检查服务器IP配置，确保使用正确的内网/公网IP。

**Q: 音效无法播放？**  
A: 现代浏览器需要用户交互后才能播放音频，请先点击页面任意位置。

**Q: 如何清空数据重新开始？**  
A: 在会话管理页面关闭当前抽奖，然后开启新的抽奖会话。
